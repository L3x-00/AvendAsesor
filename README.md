# AVEND ASESOR

Plataforma web SaaS de orientación documental para docentes mediante inteligencia artificial y arquitectura RAG.

## Estructura

- `apps/web`: Frontend desarrollado con Next.js.
- `apps/api`: Backend desarrollado con NestJS.
- `packages/shared`: Tipos, contratos y utilidades compartidas.
- `docs`: Requerimientos, arquitectura y manuales.
- `infrastructure`: Configuraciones de despliegue y servicios.
- `scripts`: Automatizaciones y scripts de base de datos.

## Desarrollo local

Frontend:

npm run dev:web

Backend:

npm run dev:api
